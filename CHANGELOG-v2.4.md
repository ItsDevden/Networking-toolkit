# Networking Toolkit v2.4 - Unified test package

- Added IPv4 dashboard with three live-synchronized numeric fields, 16-bit clickable grid, Set All, Invert, Reset, Copy Binary.
- Added IPv6 Calculator with eight editable hexadecimal groups, selected-group 16-bit toggle editor, /0–/128 selector, color-coded network/interface bits, compressed and expanded notation, network address, classification, and copy actions.
- Reordered the sidebar to put IPv6 Calculator below IPv4 and before the planners.
- Enlarged sidebar and DenDev logo; hid always-visible Move buttons.
- Retained the compact Cisco command library, CLI generator, IPv4/IPv6 FLSM planners, VLSM and Excel export work from v2.3.

## Testing caveat
This source was statically checked and the ZIP integrity verified. It has not been compiled or launched on Windows in this environment. Use a separate folder and build with Visual Studio 2022 + .NET 10 SDK. This is a release candidate for user testing, not a verified binary release.
