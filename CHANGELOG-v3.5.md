# Networking Toolkit v3.5

- IP List: replaced Location with a wide Notes column. All columns now allow manual resizing, including Notes.
- IP List: duplicate IP detection now resolves the IP Address column by name, so moving/removing columns does not break validation.
- CLI: cleaned up category organization: Router, Switch, Interfaces, Routing, VLANs, SSH, DHCP, NAT, ACL, Show.
- CLI: removed redundant entries across generic categories, while preserving device-specific basic setup under Router and Switch.
- Existing calculations, validation and Excel export remain unchanged.

This is a source package. Windows compilation/runtime testing is still required.
